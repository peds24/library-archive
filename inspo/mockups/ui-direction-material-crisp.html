Library — UI Exploration

A shelf built from Google's own materials.

Material 3 does the actual work here — filled text fields, filter chips, tonal containers, a pill‑indicator nav bar — because this runs on a Pixel and should feel like it. The restraint is borrowed from Perplexity: one hero statement, then quiet, uncluttered screens instead of Material's usual demo‑mosaic of six clashing colors.

The one liberty taken is the hexagon — a nod to the Library of Babel's endless hexagonal rooms, redrawn as a clean vector tile instead of a hand‑inked illustration. It shows up twice: as the faint grid behind this page, and as the shape of every book cover.

Vs. the first pass

Direction A (ui-direction-minimal-modern.html) invented its own indigo system. This one deliberately doesn't — it borrows Material 3's actual tokens and components so it reads as an Android app first, "designed" second.

Where the hexagon lives

Only two places: the page background here, and every book cover. Resist the urge to add it to buttons, icons, or the nav bar — one motif, used sparingly, reads as intentional; scattered everywhere it reads as decoration.

Next

If this is the direction — worth pulling the real Material color utilities (react-native-paper or a hand-rolled tonal-palette helper) rather than hand-picking hexes per screen like this mockup does.

Using the switcher
