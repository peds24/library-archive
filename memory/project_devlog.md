The project has a `DEVLOG.md` at the repo root. Every session must add a dated entry documenting what changed and why.

**Why:** This is a learning project. Pedro wants to refer back to architectural decisions and understand the reasoning behind them in future sessions or a future time.

**How to apply:** At the end of every working session (or when significant design decisions are made), add a new session block to `DEVLOG.md` following the template at the bottom of that file. Cover: what changed, any design trade-offs, and the current architecture state.
