# Book Tracker & Library Archive

A minimal home library scanner and book tracker. Catalog your physical collection, track current reads, and organize your TBR (To Be Read) in a clean, distraction-free interface. 

## Features
* **Library Management:** Scan books from your home library and display them in an organized manner.
* **Reading Tracking:** Keep track of current reads, what to read next, and your overall collection with a minimal UI.
* **Filter & Sort:** Easily sort books by genre, alphabetical order, or status (reading, read, next up, default in shelf).
* **Bulk Scanning:** Quickly add multiple books to your library using a continuous barcode scanning flow.
